🍂 秋招手帐 · 使用说明
═══════════════════════════════════════

【第一次使用】

1. 双击「install-mac.command」（Mac）或「install-windows.bat」（Windows）
2. 等待安装完成（约 1-2 分钟）
3. 安装完成后，会自动启动看板

【以后每次使用】

Mac：   双击「启动秋招手帐.command」
Windows：双击「启动秋招手帐.bat」

浏览器会自动打开 http://127.0.0.1:8000

【关闭看板】

在启动的那个黑窗口里按 Ctrl + C

【关于数据】

你的所有数据都存在本文件夹里：
· kanban_data.json    投递记录
· interviews.json     面试记录
· chat_history.json   聊天记录
· backups/            自动备份

定期备份这几个文件，就不会丢数据。

【关于 AI 功能】

默认情况下，AI 功能未启用。看板的基础功能
（投递管理、日历、面试记录、数据可视化）都可以正常使用。

如果你想要 AI 助手、面试模拟、JD 抓取等功能，
需要用文本编辑器打开 .env 文件，填入 API Key。

API Key 从哪里来：
· 火山引擎 Ark：https://www.volcengine.com/product/ark
· Tavily 搜索：https://tavily.com/（每月 1000 次免费）

【小招：说一句，看板自动更新】

直接把进展告诉小招，一次说好几家也行，它会马上写进看板：
· 「投了泡泡玛特的电商运营和品牌营销」
· 「oppo AI面做完了，大疆测评也写了」
· 「TCL 发来测评，3 天内完成」（自动算出截止时间）
· 「美团约了二面，周五下午三点」（自动记面试、状态改成面试中）
· 「焦内其实就是三立人」（改名）
每次改了什么都会列在回复下面，改错了点「撤销」即可恢复。

【日历订阅 & 微信提醒】

· 日历视图 →「订阅到系统日历」：测评截止和面试会出现在 Mac 日历里，自动提前提醒
· 在 .env 里填 SERVERCHAN_KEY（Server 酱）后，截止前 24h/2h、面试前 24h/1h
  会推送到微信，每天早上 9 点推送当日待办（看板开着时生效）

【SQL 数据库（练 SQL 用）】

看板的正式数据仍是 JSON 文件；每次数据变化，会自动同步一份到
SQLite 数据库 kanban.db（同一文件夹里），专门用来查询和练习：
· 看板工具栏点「🗄 SQL」：写 SELECT 查询、看结果表格，有 10 个由浅入深的例子
  （WHERE、GROUP BY、JOIN、子查询、日期函数、CASE、跨库 JOIN）
· jh. 开头的表是求职助手的 jobs.db，可以和看板的表一起 JOIN
· 也可以用别的工具打开 kanban.db：终端输入 sqlite3 kanban.db，
  或者用 DB Browser for SQLite（免费图形界面）
· kanban.db 是只读副本：在里面改数据不会影响看板，下次同步会被覆盖；
  想改数据请在看板里操作或跟小招说

【遇到问题】

如果双击安装脚本没反应：
· Mac：右键点脚本 → 选「打开」→ 弹窗里再点「打开」
· Windows：右键点脚本 → 选「以管理员身份运行」

如果提示「未检测到 Python」：
· 先去 https://www.python.org/downloads/ 安装 Python
· Windows 安装时务必勾选 "Add Python to PATH"
